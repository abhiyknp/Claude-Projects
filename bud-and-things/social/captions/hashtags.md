# Hashtag sets

Keep to **5 to 8 hashtags per post**. Instagram has been cutting how many hashtags a post can carry, and a few relevant ones work better than 30. Every caption in `instagram.md` already ends with a ready set; this file lists the sets so you can swap them. Mix one brand set with one or two topic sets. Never use a hashtag you have not looked at (search it once: if the top posts are unrelated, skip it).

| Set | Use for | Tags |
|---|---|---|
| **BRAND** (always) | every post | #budandthings #byashi |
| **CANDLE** | candle posts | #handpouredcandles #scentedcandles #candlelover #candlesofinstagram |
| **JES** | Jesmonite objects | #jesmonite #trinkettray #handmadehome #homedecorindia |
| **PROCESS** | making and Reels | #candlemaking #makersgram #satisfyingvideos #smallbatch |
| **GIFT** | gifting | #giftideas #thoughtfulgifts #giftsforher #giftingindia |
| **XMAS** | Christmas | #christmasgifts #secretsanta #christmasgiftideas #festivegifting |
| **NY** | New Year | #newyear2027 #newyearritual #newyearsgift |
| **LOCAL** | any (use 1 to 2) | #greaternoida #noidablogger #delhincr #supportsmallbusiness |
| **CARE** | care and tips | #candlecare #candletips #candlenight |
| **FEST** | Kartik Purnima, Gurpurab, festive | #kartikpurnima #devdeepawali #festivelights |

**Pinterest and YouTube:** use keywords in the text rather than hashtags. At most 3 hashtags in a Short's description.

**Don't use:** #like4like, #followforfollow, #viral, #ad (unless it is one), or hashtags that claim things we cannot prove (#organic, #natural, #nontoxic, #ecofriendly).

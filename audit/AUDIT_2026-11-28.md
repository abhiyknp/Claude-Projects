## What I checked, how, and the result

1. **UI / UX.** All 21 test suites in `audit.yml` (13 pages at 1280 and 390 px, 2,630 text items, shop flow, festive, photo fallback, consent, backup, shipping, publish pop-up, offline orders). My scan of 13 pages × 2 widths: no sideways scroll, no console errors; tap targets: only inline links in sentences and checkboxes inside full-width labels are under 44 px (fine). Snow: honours reduced motion, stops when the tab is hidden, ends after `festiveUntil`, canvas never takes taps. Result: pass after F-05.
2. **Functional.** Mock database flow test passes (cart, checkout, payment states, stock, owner actions). Ran `clean-test-data` on 5 offline + 2 test orders: tests removed, 5 marked Delivered, no messages queued; a second run changed nothing; with 0 offline orders it stopped and changed nothing. Result: pass.
3. **Code.** Read `pay`, `delivery` booking, `mark_paid`. Amount comes from the server order (`o.total * 100`), webhook signature checked with a constant-time compare, repeats are no-ops, rate limits on start and verify, `mark_paid` callable only by the server. Result: pass, one note (F-06).
4. **Security.** Secret scan (1,611 files) pass; git history grep for live keys and passwords: none (only placeholders). `config.js` holds only public values. Settings table public (F-02). Preview code in docs (F-03).
5. **Text.** Searched for burn time, eco, natural, soy, organic, toxic, safe, allergy, vegan: only burn time was a problem (F-04). "Hand-poured" (98 times) and "small batches" (23 times) are true only if you pour by hand in small batches; keep a photo or batch record as evidence.
6. **Data.** Master sheet (49 rows) vs `catalogue/products.json`, `catalogue.sheet.json`, `labels.products.json` and the database after all 8 SQL files: every price and show-on-website flag matches (F-07, F-08 aside). Each SQL file ran twice on a throw-away PostgreSQL: no errors, the second run left the data the same (only `updated_at` changes).
7. **SEO.** Covered by the page audit (titles, descriptions, JSON-LD prices). Not re-checked live.
